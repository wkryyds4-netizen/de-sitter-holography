## 恢复的对象

旧 X=(1−hatΠ)mZ2 是额外投影后的场，其结果继续成立。当前恢复被投影去掉的动态后代，定义 U2=mZ2−C2,N，其中 C2,N 是逐样本与 h 对易的明确多项式。raw 五字恒等式与既有第二 chaos 表给

U2 = X + bR JhR + bF JhF + bJ Jh²Y + bD Lh²Y + CκY + o(L²)。

JhA={h,A}/2，LhA=[h,A]；Y、R/F、U2 的能量维数分别为 2、3、4。设 d3=q²−q+1，d5=1+q+q²+q³+q⁴，则

- bR=−2(1−q)²/d3，bF=2(q−1)，bD=q²/(4d5)。
- bJ=(1−q)²(q⁴−q³−2q²−q+1)/[(1+q²)d5]。
- κ=(1−q)(1+q)²/d5+8λq²ρ；ρ=v/(v+dv)，v=2λ(1−q)+16λ²q/(1+q)，dv=2λ(1+q)。

守恒反项保留实际 C_N、c_N、e_Q 及 λ_N、q_N，特别保留 renewal 中 A²/m 的守恒贡献。不得在随 p 增长的反项中提前换成极限参数。

记 e=(E+E′)/2，ω=E−E′，H2=bJ e²+bD ω²+Cκ。由前阶段五场的完整两能量正交性，

ν_U2 = V4 μ_q⁴ + V2 μ_q² + bR²e² VR μ_q³ + bF²e² VF μ_q + W H2² μ_q²。

这里 μ_qʲ 表示参数为 q 的 j 次幂的既有 Mehler 测度。交叉谱为 ν_Y,U2=W H2 μ_q²，以及 ν_L,U2=aeW H2 μ_q²+bFeVF μ_q+bReVR μ_q³。后者普通中心时间积分为零，但双能量测度本身一般不为零。谱矩阵的正分解和行列式见稿第4节。
