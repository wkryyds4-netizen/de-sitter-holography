# 从两点传播到多 singlet 与连通四点

2026-11-06。沿 Susskind complex DSSYK 主线，把上轮的两点等价推进为任意固定阶联合矩的等价，并实际计算一条实时四点切片。正式稿见 [LaTeX](../manuscript/susskind-singlet-multimark/main.tex) 与 [PDF](../output/pdf/de-sitter-susskind-singlet-multimark.pdf)。所有材料先保存在本地，不提交或推送 Git。

## 主要结果

模型仍为标准 CAR、完整 Hermitian Gaussian G、允许指标集交叠，β=μ=0 全归一迹。H=H_s 生成 string time，ℏ=1，w=4ᵖ(J_s²/λ)(p!/Nᵖ)²；先 N,p→∞ 固定 λ=p²/N>0，再讨论小 λ。沿用 O=A−EA(Q)、A=Σ[H,cᵢ]†[H,cᵢ]、B=H²−EH²(Q)。定义

\[
q=e^{-4\lambda},\quad \sigma^2=J_s^2/\lambda,\quad
c=2\lambda\frac{1-q}{1+q},\quad
X=\frac{O-cB}{\sqrt{W_d}},\qquad
W_d=4J_s^4\left[\lambda^{-1}+\frac{4q}{1+q}\right].
\]

此 X 与 H/σ 的所有固定长度联合矩，等于两种字母的弦配对和：只配同种字母，交叉权为 HH:q、HX:q²、XX:q⁴。这是已有 mixed-q Gaussian / 多弦结构；本轮推导的是这个同 G 导数复合算符确实化到它。不是宣布有限 N 下算符等同于独立随机探针，也不是把已知四点核改称我们的新解。

因此任意固定实时的奇数 X 关联为零；等时 ⟨X⁴⟩=2+q⁴、⟨X⁶⟩=5+6q⁴+3q⁸+q¹²。奇数消失是此归一化动态通道的双标度结论，不假设原 Hamiltonian 存在 X→−X 的逐样本对称性。

## 已实际计算的实时四点

用 G_r 表示上轮已核准的单位归一 q-Mehler 两点核，G_r(0)=1，⟨X(t)X⟩=G_{q²}(t)。把四个插入排成 X(t)X(t)X(0)X(0)，内部配对给1，其余两种配对给相同的双弦传播核，权分别为1和q⁴：

\[
F_{22}(t)=\langle X(t)^2X(0)^2\rangle=1+(1+q^4)G_{q^4}(t).
\]

减去三个断开配对后的普通连通四点是

\[
\kappa_4(t)=(1+q^4)G_{q^4}(t)-2G_{q^2}(t)^2.
\]

它不是 OTOC。连通的含义是 annealed state 的普通 cumulant，不是逐样本 cumulant 再平均。已算 λ=.25,.1,.05,.02,.01 和 J_s t∈[0,1.5] 的61个时间点；五条曲线在 t=0 负，在 J_s t=.5 正。比如 λ=.01 时 κ₄(0)=−.147856、κ₄(.5/J_s)=.000880010。数值不是严格区间认证，精度和相消记录见下。

解析量为

\[
\kappa_4(0)=e^{-16\lambda}-1=-16\lambda+O(\lambda^2),\qquad
\kappa_4''(0)=2\sigma^2(3-4q^2+q^8)=768J_s^2\lambda+O(J_s^2\lambda^2).
\]

这提供偏离普通 Gaussian 配对的定量指标，领先阶与 Susskind 修正后的 g_open²=λ 字典相容。还不能从这个符号直接读出吸引/排斥力或体散射振幅。应用已知 small deformation 极限 G_{qᵈ}→sech^{2d}(2J_s t)，得到 κ₄(t)→0；一般 t 的首阶 λ 系数必须同时展开两个 G，不能只展开外部系数1+q⁴。

## 一般证明

每个复合插入扩成相邻两个 H 槽，Gaussian 中心化精确删除内部配对。m个标记、n个普通H有L=n+2m个槽。局部行列式 F=det(I+ZT(h)Pπ)，T_ab=±1/2，标记使 T_ba→T_ba−h。有限系数为 w^{L/2}(−1)^{Lp/2}[z₁ᵖ…zLᵖ]∏(∂h−c)Fᴺ|h=0。

无内部配对即无 marked singleton。固定L下，二集交叠为独立Poisson(λ)，三重交叠概率≤binom(L,3)p³/N²→0；hypergeometric指数矩和Hölder控制一致可积，复标记邻域的Cauchy导数可过极限。每图余下指数只有 λΣα_j h_j+λΣδ_ij h_i h_j，α=2ε，δ=4仅两标记完全由两条嵌套弦相连。

移去c后，每个单标记均值是 ℓ=λ(α−2u)，u=(1−q)/(1+q)。若一个标记不是双弦连接到另一个标记，则它的全部δ为零，必含ℓ。交换它的相邻端点只翻转其自身ε；即使另一mark共享一条弦，也不改变另一mark的ε。轨道相消式为(2λ−c)+q(−2λ−c)=0。三角环和更长环因此全部消去。

仅剩标记两两完整双弦配对。每对嵌套/交叉两图和为

\[
D=(2\lambda-c)^2+4\lambda+q(-2\lambda-c)^2
=4\lambda+16\lambda^2q/(1+q)=W_d/\sigma^4.
\]

压缩双弦后，穿H为两次交叉，穿另一双弦为四次；除以各插入√W_d就得联合矩定理。已有mixed-q正迹表示保证候选存在。有限N各固定偶矩有界，通过真实轴指数Taylor余项的Lˢ界和tracial Hölder，先DS后Taylor阶数K→∞，得到所有固定有限时间关联收敛；不是未经证明交换有限N无界指数级数。技术证明见附录。
