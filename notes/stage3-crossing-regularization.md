# 交叉 6j 核的循环换图与双对角消极点

日期：2026-10-29。模型、质量与测度约定沿用 [四点来源映射](../literature/stage3-fourpoint-source-map.md)。主来源固定为 Kolchmeyer–Liu，[arXiv:2411.08090v1，(6.26)—(6.27)、(A.14)、(B.21)—(B.24)](https://arxiv.org/html/2411.08090v1)。本稿说明新的点值 API；不修改已绑定 76 项验证的旧实现或旧结果，也不执行高维积分扫描。

## 1 返回哪个核，以及哪些参数可以输入

新模块为 [observer_crossing_regular.py](../code/observer_crossing_regular.py)：

```python
from observer_crossing_regular import RegularCrossingEvaluator

evaluator = RegularCrossingEvaluator(dps=25, guard_digits=15)
result = evaluator.evaluate(nu, a, b, c, d)
S_symmetric = result.symmetric_s
X_HH = result.hh_cross
X_given_d = evaluator.conditional_cross(nu, a, b, c, d)
```

`dps` 是目标十进制精度；`guard_digits` 及近退化补偿用于增加工作精度。默认最大外层工作精度 180 位；精度预算或数值诊断不满足时明确抛出异常。`mpmath.diff` 和特殊函数可使用更高内部精度，180 并非整个求值的峰值上限；`max_observed_formula_dps` 另记导数回调时观察到的公式精度。输入使用十进制字符串可避免先引入浮点二进制误差。

有效数学域是 ν,a,b,c,d 均为严格正的有限实数，包括单一对角 a=c 或 b=d、双对角 a=c 且 b=d，以及四者全部相等。端点 s=0、ν=0、复质量和非 principal-series 延拓不在此 API 范围。数值实现并不保证给定预算能成功处理该域内任意极大参数；失败不能替换为零或强制实部。

返回的 `symmetric_s` 是原 (A.14) 的 ℳS；`hh_cross` 是未归一化 HH 密度

\[
X_H(a,b,c,d)=a\sinh(\pi a)b\tanh(\pi b)
c\sinh(\pi c)d\tanh(\pi d)\,\mathcal S^\nu(a,b,c,d).
\tag{R1}
\]

`conditional_cross` 返回 X_H/ρ_H(d)，相对于 da db dc；完整外包还须乘 P_f(d)dd。所有接口都保留原始复值，没有取实部的隐藏步骤。Gamma 常数仍是 (A.14) 的 1/(4096π¹¹)，而 (B.21) 的 S 自身包含 π⁻³；没有添加新的归一化。

## 2 单一对角：换完整 ℳS 的坐标图

原 (6.26) 后明确说明 ℳS 具有四次循环及反射对称性。完整 X_H 只满足带 cosh 比值的 (6.27)，不具有同一循环对称性。因此先选适合计算 ℳS 的标签顺序，最后始终用**原来的** a,b,c,d 计算 (R1) 前因子。

(B.21) 这张表达式的显式单项极点位于第一、第三标签相等之处。定义

\[
g_1=|a-c|,\qquad g_2=|b-d|.
\tag{R2}
\]

若 g₁≥g₂ 且至少一者非零，使用 (a,b,c,d)；若 g₂>g₁，使用循环图 (b,c,d,a)。这样第一、第三差为 max(g₁,g₂)，避免不必要的数值消去：

- a=c、b≠d 时，转到 (b,c,d,a)，不引入小偏移。
- b=d、a≠c 时，原图已经有限；旧模块对这一情形的拒绝只是此前保守的有效域限制。
- 两差同时为零时，任何 D₄ 换图仍在对角上，需要下一节的解析有限部分。

对非常小但非零的差，额外工作位数按 −log₁₀[max(g₁,g₂)/max(1,a,b,c,d)] 增长。输入先以最大允许外层精度解析，并用输入的精确有理数表示比较两组相对标签。如果不同输入在解析时被合并，则明确报精度预算错误，不把它们称作精确对角。还根据四项抵消量及原始虚部进行有限次精度提升。这些是数值保护措施，不是区间误差认证。

## 3 双对角：从 B.21 解析提出唯一极点

记原 (B.23) 的 Gamma 比为 ℬ(u,v)。定义去掉最后一个分子 Gamma 的函数

\[
\mathcal B^\circ(u,v)=
\frac{\sqrt\pi\,\Gamma((1-u)/2)\Gamma((1-v)/2)}
{\Gamma(u/2)\Gamma(v/2)\Gamma((2-u-v)/2)},
\]

\[
\mathcal B(u,v)=\Gamma((u+v-1)/2)\mathcal B^\circ(u,v).
\tag{R3}
\]

这里 ℬ 不是 Euler beta。设 δ=a−c，且 h₁,…,h₄,h,k 依照 [来源映射 (F23)](../literature/stage3-fourpoint-source-map.md)。由于 h₂+h₄=1、h−k=iδ：

- 第一个 G 的第一项，在第二个 ℬ 中出现 Γ(iδ/2)；
- 第一个 G 的第二项，在第三个 ℬ 中出现同一个 Γ(iδ/2)；
- 第二个 G 的参数为 (h₃,h₄,h₁,h₂,1−h,1−k)，相同两处给出 Γ(−iδ/2)。

把这四个 ℬ 分别替换为 ℬ°，其余 Gamma 与 ₄F₃ 全部保留。第一个 G 的两项和称 A(δ)，第二个 G 的两项和称 B(δ)，便得到精确恒等式

\[
\boxed{\pi^3 S(a,b,c,d,\nu,\nu)
=\Gamma(i\delta/2)A(\delta)
+\Gamma(-i\delta/2)B(\delta).}
\tag{R4}
\]

A、B 的定义仍来自 B.21—B.24，不是对 S 做拟合。代码中的 `stripped_branches` 实现这一解析拆分。对严格正质量，去掉上述极点之后，其余 Gamma 参数没有相应零极点；₄F₃ 的参数 excess 恒等为 1，下参数在该实参数域中不会成为非正整数。因此 A、B 在对角附近是解析函数，参数微分可由局部一致收敛的超几何表达定义。

### 3.1 为什么两个留数相等

a=c 而 b≠d 时，第二节的旋转图给出有限 ℳS，(A.14) 的 Gamma 乘积处处非零且有限，故 S 也有限。(R4) 的 1/δ 系数因此必须消失，即 A(0)=B(0)。A、B 去极点后连续，令 b→d 便将这一恒等式延伸至双对角。这个论证使用原文的完整 ℳS 对称性；没有假设未装配的 S 或单个 Gamma 块对称。

原附录 (B.10)—(B.14) 的绝对积分控制也可独立支持连续性：实标签时七个实部指数均为 −1/2。对该积分的局部可积性及参数正则性，须保留相应的对数权重或小复参数条带控制；不能仅凭每一点的连续被积函数就交换极限。

### 3.2 有限部分公式

在双对角 (x,y,x,y) 上使用中心路径

\[
(a,b,c,d)=(x+\delta/2,y,x-\delta/2,y).
\tag{R5}
\]

这使 a+c 固定且 a−c=δ。由 Γ(z)=1/z−γ_E+O(z) 及 A(0)=B(0)，

\[
\boxed{S(x,y,x,y,\nu,\nu)
=\frac1{\pi^3}\left[
\frac2i\bigl(A'(0)-B'(0)\bigr)
-\gamma_E\bigl(A(0)+B(0)\bigr)\right].}
\tag{R6}
\]

随后乘原 (A.14) 在对角处的十六 Gamma 乘积与 1/(4096π¹¹)，得到 ℳS；再用原标签的 (R1) 得到 X_H。Gamma 乘积无需单独求导，因为 (R4) 的极点已经整体消去，剩下的是一个有限 S 的普通乘积。

实现对解析的 A−B 使用 `mpmath.diff` 中心差分并增加内部精度；`addprec=15` 的单位是 bits，内部导数回调的精度约为外层的两倍再加约 18 个十进制位，实际数值另行记录。这与对发散的原 Gamma 项做小偏移相加不同。公式 (R6) 是解析消极点结果，导数值仍是数值求值，因此通过独立工作精度、留数残差和多方向逼近核验。

### 3.3 一次保留的失败与对应修复

初版测试中，普通点、单/双对角及多方向逼近都通过，但 a−c=10⁻²⁴ 的附加检查失败：25 位目标、64 位外层工作精度下，与精确对角的相对差约 9.36×10⁻¹⁸，超过该测试的 10⁻²⁰ 阈值；虚部却仍极小。原始 226 项、1 项失败的记录保存在 [crossing-regular-initial-validation.json](../results/stage3/fourpoint/crossing-regular-initial-validation.json)，其旧代码哈希不应与修复后的文件匹配。

原因是原 B.21 各 ℬ 中的 δ 由几个数量级为 1 的 h 参数相减重新形成。这一步先损失一组近对角有效位数，之后四个约 1/δ 的项相消又损失一组；仅看完整虚部无法察觉这种实部误差。

修复后的非零 δ 路径同样使用 (R4)：从原标签直接计算 δ，独立求 Γ(±iδ/2)，再乘去极点的四项。这样避免在 ℬ 的参数组合中重新形成极小差。对角路径仍使用 (R6)，没有把小差直接设置为零。最终验证同时比较极近非零点的两档精度及其对角极限，而不只检查实性。

## 4 验证设计与误差口径

[验证脚本](../code/validate_crossing_regular.py) 将全部原始复数、导数、留数差、换图位置、实际工作精度、抵消量和耗时保存在独立的 [crossing-regular-validation.json](../results/stage3/fourpoint/crossing-regular-validation.json)。它核查：

1. 两个既有非退化点的 S 与 HH 常数同旧 76 项结果一致。
2. 非退化点上 (R4) 的解析提取与原 B.21 四项直接和一致。
3. 两种单对角、两个不等质量双对角及一个全相等点的 25→40 位目标精度比较。
4. 每类点的完整 D₄ 对称性，以及由**原标签**前因子造成的 HH 加权变换。
5. 对双对角和全相等点，从不同方向接近，先用 ±h 平均消去奇数阶，再使用两级 Richardson 消去 h²；这些逼近仅作独立验证，生产 API 不用外推值替代 (R6)。
6. 一个 10⁻²⁴ 的非零差仍走非退化图，并增加相应保护位数；没有把它直接当作对角。

多方向测试保存 h=2×10⁻⁴、10⁻⁴、5×10⁻⁵ 的全部原值和 Richardson 差。精度差及外推差是经验数值诊断，没有称作严格区间界。不同方向一致可排除若干实现错误，不能替代第 3 节的解析有限部分论证。

### 4.1 本轮结果

最终结果为 **231 项通过、0 项失败、0 个求值异常**。两份当前代码、旧模块与旧 76 项结果的哈希均已读回核对；旧 76 项 provenance 全部仍匹配。

在本轮有限测试集上，25→40 位目标精度的最大相对差约 1.36×10⁻⁴⁰，D₄ 对称性残差最大约 2.04×10⁻⁴⁰。显式 pole-factor 恒等式与原 B.21 和的差约 1.55×10⁻⁵²。五条独立接近路径的精细 Richardson 值与导数式相对差最大约 1.29×10⁻¹⁴；两级 Richardson 变化最大约 1.93×10⁻¹³。这些是各检查自己的经验残差，不合并成一个全域精度保证。

代表双对角的未归一化 HH 点核为：

| ν | (a,b,c,d) | X_H |
|---:|---|---:|
| 0.6 | (0.6,0.8,0.6,0.8) | 1.26552447179225877874×10⁻⁶ |
| 0.6 | (0.6,0.6,0.6,0.6) | 4.52729320116054178962×10⁻⁶ |
| 1.0 | (0.4,1.2,0.4,1.2) | 2.10472518231422070719×10⁻⁹ |

修复后 10⁻²⁴ 非零差的两档精度相对差约 1.11×10⁻⁴¹；它仍被明确记作非对角点。更长、超过最大解析精度的不同输入被拒绝，不会静默当成相同标签。

本机测得：25 位目标下，四个普通/单对角代表点约 0.53—0.63 秒，双对角约 6.0—9.6 秒；40 位目标下双对角约 12.3—13.6 秒。这些耗时只反映当前测试点。40 位目标的双对角外层为 55 位，导数回调观察到 129 位；与外层精度上限的区别已在结果中显式保存。

## 5 后续条件积分的接口边界

对于外质量 d 固定、时间从左至右为 (t,0,t,0) 的任务，完整相位为 exp{i[m(a)+m(c)−m(b)−m(d)]t}。该相位、四个 Gaussian 因子、HH 前因子及 ℳS 都在 a↔c 下不变。因此可在 a<c 的三角域积分后乘 2，把 a=c 视作测度零边界；这条积分路线可以独立于双对角算法推进。

新 API 使普通矩形/其他配置的节点不必人为偏离对角，也提供边界交叉核验。它本身没有证明三维或四维谱积分的绝对可积性，没有提供统一的大质量误差估计，也没有完成有限 G 或其他维数的推广。涉及质量上截断的物理 pairing 误差，应继续使用二步态的正范数尾与 Cauchy–Schwarz 控制；不要把本页点值精度当作积分误差。
