## 本轮解决的缺口

上一轮只知道固定L,R的紧盒常数有限。本轮证明它可控制为

    C'_L,R,ε + C''_L,R ≤ C exp[c(L+R)] (1+L+R)^d,
    M ≥ C0(1+L+R)²。

常数C,c,d,C0独立于L,R,M，依赖固定物理参数与ε；它们尚未给出可直接用于百分比误差的数值。这个增长类别足以把增长盒代入第16节误差界，消除了此前只能使用未知δ_M定义窗口的缺口。

## 为什么没有隐藏的更快增长

1. 固定竖直带内的小Gamma函数、倒数和有限阶导数，离开固定半径的极点小圆后，以参数虚部的指数乘多项式控制。大实偏移只改变这些虚部；Euler实部积分裕量和极点小圆半径不必缩小。
2. 大Gamma比值不直接套“固定平移”渐近。令Z=±iλ，λ与M成比例，对平移a,b沿连接线积分ψ(Z+z)−log Z，得到解析对数误差≤C(1+Q0)²/M，条件M≥C0(1+Q0)²。Q0为偏移尺度，不是质量投影。这样显式控制平移随盒增长的情形。
3. 连接公式中的三种Gauss函数均具有Euler积分，且所有底数是正实数。虚指数在积分内部模长为一；对z求固定阶导数，只增加Pochhammer多项式和可积的t权重。式(17.4)保留普通₂F₁所需的Γ(C)，避免把DLMF的正则化函数误当普通函数。
4. J(w)的有限阶导数由exp(−w/4)乘w,Q0多项式控制。固定cutoff、w=1/|Z|分割和四次分部积分给端点余项，所需导数阶数不随Q0增长。除去一阶Taylor项后的余函数需要到四阶导数，原平滑幅度到五阶足够。
5. 四支额外项的解析抵消保持精确。用固定半径e,δ圆盘的最大模原理去掉表面极点；原三重积分的复管实部裕量不随实偏移改变。外腿大Gamma质量指数与双曲prefactor先抵消，剩余误差仍是同一增长类别。最后真实能量偏移、Jacobian、普通紧盒体积只增添多项式。

## 显式误差与截断

新增外包条件为存在β0>0，使B0=∫exp(β0 r)π0(r)dr有限。Gamma密度可取β0=β/2、B0=2^(p+1)；间隙指数包为B0=2exp(βg/2)。不对任意L¹外包宣称下面的速率。

令ℓ=log(2M)。对于任意固定q>0，选

    L_M = (q+2)/β0 · log ℓ,
    R_M = sqrt[8(q+2)/σ² · log ℓ]。

外包尾和正范数谱尾均为O(ℓ^(−q−2))；局部常数仅增长为ℓ的某个有限幂，乘M^(−1+ε)后比任意逆ℓ幂更小。因此全实时间轴一致误差

    δ_M = sup_t |D_M(t)−D_M^(2)(t)| = O_q(ℓ^(−q))。

交叉项及有序范数也分别满足该结论。第16节中两支尾的控制来自极限曲线与平台的正范数界，没有额外的log M绝对核尾损失。

还可证明存在κ>0使δ_M=O(M^(−κ))。在ε=1/8时，若c为增长界中已放大的指数系数，可取κ=β0/[8(c+β0)]、L=log M/[4(c+β0)]、R=sqrt[16κ log M/σ²]。这个κ依赖尚未数值认证的c，所以不报告一个虚构的数值指数。显式逆log窗口不依赖知道c的数值。

## 已能转移到精确有限M的结论

以下D_M指精确模型，不是此前两支领先核的数值冒充。

- 非退化Gamma端点的实系数c_p≠0；n偶p为p+3、奇p为p+4。任意固定0<α<1，取s=ℓ^α、t=ℓ−s，则D_M−D_edge=c_p ℓ^(−αn)乘〔1+O(ℓ^(−α)+ℓ^(−n(1−α)))〕。特别是s=sqrt ℓ现已成立。β=1时p=1、2保持负号。
- 若s=aℓ，0<a<2，则必须保留两支：D_M((1−a)ℓ)−D_edge=c_p ℓ^(−n)〔a^(−n)+(2−a)^(−n)〕+O(ℓ^(−n−1))。正物理时间取a<1，结论在a的内部闭区间上一致。
- 有界固定物理t下，D_M(t)−D_edge=2c_p ℓ^(−n)+O(ℓ^(−n−1))。这是有限M趋近静态平台的速率，并非新引力动力学。
- 有界固定T下，D_M(ℓ+T)−D(T)=c_p(2ℓ+T)^(−n)+O(ℓ^(−n−1))。这时快速支确实支配这一幂律误差；需要本轮误差界才能这样说。
- F指数尾：任意b>0、2<h<4，t=ℓ−b log ℓ时，D_M=2C ℓ^(−2b)乘〔1+O_h(ℓ^(−(h−2)b))〕。未宣称固定T下M⁻⁴镜像项必为精确误差首项。
- 固定间隙的两条振荡四次尾也可在相应log幂窗口中转移，先作绝对包络比较；振荡零点附近不作均匀相对误差断言。

临界奇p系数为零、g→0统一跨越、一般无指数矩外包均未由以上主系数式覆盖。显式渐近形状不等于“已知一个实验所需的最小M”。
