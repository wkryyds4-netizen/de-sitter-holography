# 三阶导数 singlet：一个独立的动力学方向

2026-11-06，本地阶段；正式推导见 manuscript/susskind-cubic-singlet/main.tex，阅读版 output/pdf/de-sitter-susskind-cubic-singlet.pdf。本轮不 commit/push/ZIP。

我们沿 Susskind 的独立 singlet 族往前走了一阶。核心结果是：三阶双线性并不全是已有算符的时间导数；正确扣除后留下正范数、有非零动力学的方向，其低阶矩与 q³ 探针吻合。

## 算符先分清

标准 CAR，H=Hs，完整退火 trace，β=μchem=0。H 每个正规序项含 p 个产生与 p 个湮灭；包括指标重叠。L=ad_H，A=Σ(Lc)†Lc。精确有限 N 恒等式：

M₃=Σc†L³c=T₃+(3/2)LA，T₃=(M₃+M₃†)/2。

由 B_ab=Σ(L^a c)†L^b c、LB_ab=−B_(a+1,b)+B_(a,b+1) 及 M₁=−pH、M₂=A 直接证明。真实时间导数是 i^n L^n，不能把 MSS 的示意式逐个符号直接搬进当前规范。

令 D(Y)=Q_fY−Σc†Yc，正规序 k-body 项满足 D(Y)=kY。于是

A=(2p−D)H²，
T₃=(3p−D)H³−(3/2){H,A}。

三因子间收缩计数记 K12、K23、K13，则 T₃=K13−(K12+K23)/2。非相邻 K13 的 determinant mark 已独立用有限 CAR 对照。

## 我们实际计算的算符

W₃ 是 Gaussian coupling 的第三混沌投影；每个三次 J 单项式减去三个内部两两收缩，不是费米子正规序。定义

T=W₃T₃，S=W₃({H,A}/2)，Z=W₃H³，
R=T−aS−bZ，
a=−(1−q)²/(1+q²)，
b=2λ(1−q)(1+q³)/[(1+q²)(1+q+q²)]。

先 DS：N,p→∞、λ=p²/N 固定；q=e^(−4λ)，σ²=Js²/λ。六个跨三槽 Gaussian 配对给 Gram 矩阵，完整矩阵在 PDF 和 results/susskind-cubic-singlet/study.json。

R 同 S、Z 正交，且

〈R²〉/σ⁶ = 4λ(1+q)[1−q³+4λq²(2q²−q+2)]/[(1+q²)(1+q+q²)] > 0。

这在全部 λ>0 成立；小 λ 时 〈R²〉~32Js⁶/λ。它不是只靠某几个数值点判断非零。

原始 T₃ 的一次 Gaussian 分量尚待单独求出，不能擅自当成 H 丢弃。我们当前结论明确针对 W₃ 后的 R。H→−H 和耦合复共轭对称性还给出 R 对既有偶二阶 X 的所有简单 L 后代正交；但这本身不能排除能量加权复合物，所以仍计算了 S、Z 的投影。

## 动力学与 q³ 线索

对 K_ij=〈(LY_i)†LY_j〉/σ⁸，每个八槽排列有 42 个允许配对。只排除三槽插入内部配对；外部 H 可以与插入配对，不能只保留四对全跨。

v=(1,−a,−b)，精确 vᵀKv=2(1−q³)V，其中 V=〈R²〉/σ⁶。归一化二阶频率矩：

μ₂=2Js²(1−q³)/λ →24Js²。

μ₄=2Js⁴(1−q)²(1+q+q²)(3q³+6q²+6q+5)/λ² →1920Js⁴。

更强的有限阶结果：F_uv=〈RH^uRH^v〉/(〈R²〉σ^(u+v))，

- F00=1；
- F20=F02=1，F11=q³；
- F40=F04=2+q，F31=F13=q³(2+q)，F22=1+q⁶+q⁷。

这九项与 BNR 独立探针 r=q³ 的规则完全相符；相应 18 个 R–S、R–Z 交叉矩为零。不是预先套用独立随机探针核，而是用同一 J 的标记计算得到。

下一步若证明任意 u,v 的归约，便可引用已有 q-Mehler 核；固定 string 时间小 λ 的候选函数是 sech⁶(2Js t)。目前完整函数仍是猜想。频率矩不等于体质量谱，独立方向也尚未完成单粒子分类。
