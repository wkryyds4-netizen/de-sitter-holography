# flip-domain 来源记录

2026-11-01。原文缓存仅本机保留；版本/哈希在 results/stage4/flip-domain/source-record.json。阶段稿引用已有公式，不作数学原创性声明。

- [KS 2112.13329v2](https://arxiv.org/pdf/2112.13329v2)：本机缓存首页v2，2024-06-21。§6.3极点/产品、§6.4 Prop.6.11和§6.5 Prop.6.15；第51页跨手征交换及复参数延拓已核版。本文诊断限定字面谱乘法表示。
- [Kim综述2308.02934v2](https://arxiv.org/html/2308.02934v2)：§3两变量相位、Weyl条件、§6.2引用链。综述命题编号不覆盖KS缓存版本编号。
- [Goncharov0706.4054v2](https://arxiv.org/pdf/0706.4054v2)：§2.3测试空间与§2.4–2.5证明框架；本轮没有独立核完所有引理。
- [FG math/0702397v6](https://arxiv.org/pdf/math/0702397v6)：Thm.5.6生成元分类和eq.(87)的条带条件；Prop.5.8卷积逼近及图拓扑，后续Thm.5.4延拓。PDF第38页已全页渲染核公式；正实参数条件没有自动传到复参数。
- [Kim pseudo-Kähler 2112.13962v2](https://arxiv.org/pdf/2112.13962v2)：§5正规算符定义、§7 Props.7.3–7.4、§9 Props.9.1–9.2。PDF第21页已全页渲染，eq.(64)后明确使用Prop.7.4；不能将其视为独立解除KS延拓疑问的证明。
- [Pusz–Sołtan math/0604613v1](https://arxiv.org/pdf/math/0604613v1)：§2 Def.2.1，§3 Prop.3.1。第3页全页核版；regular q² pair具有指定谱支撑和bicharacter协变性。本文当前乘法表示不满足其谱条件。

本轮搜索亦定位 Faddeev1201.6464 与 Woronowicz2000 quantum exponential 的相关路线，仅作为后续候选；未核全部主定理，不用于宣称当前恒等式已解决。作者站Woronowicz PDF由web访问失败，改核可读的Pusz–Sołtan原文及其明示假设，不把镜像摘要充当证明。下载新增四份arXiv缓存初次受网络沙箱限制，获工具权限后成功；旧缓存不改。

更完整的条件与待查项见[证明依赖图](flip-proof-dependency-map.md)。
