# 峰面完整核极限：来源与使用边界

2026-10-31。本阶段沿用既有物理字典与 Wilson 反射；以下记录本轮推导中实际核查的来源和用途，未新增全文缓存，旧 sources/manifest.json 保持。

- Liu、Perlmutter、Rosenhaus、Simmons-Duffin，[d-dimensional SYK, AdS Loops, and 6j Symbols，1808.00612v3](https://arxiv.org/html/1808.00612v3)：式 (3.35)–(3.38) 为 Ω 与两个 4F3 的起点。物理 CG 归一来自项目已有字典；不能把文中标准核直接等同于任意观察者可观测量。
- Groenevelt，[The Wilson function transform，math/0306424v1](https://arxiv.org/html/math/0306424v1)：对偶、Proposition 4.4 的 c 展开及参数置换，支撑上一阶段反射。此处未把 Wilson 正测度域的酉性移植到物理 dS 标量子块。
- NIST [DLMF §5.11](https://dlmf.nist.gov/5.11)：移位 Stirling 与 digamma 渐近；大参数离开负实切口、紧移位的一致性用于相位和有限质量余项。完整系数的各阶抵消另由本项目符号列表核对。
- NIST [DLMF §4.36.1](https://dlmf.nist.gov/4.36)：sinh 无限乘积，用于大参数伴随级数逐项界；再结合项目项比多项式控制整个和。
- NIST [DLMF §16.4](https://dlmf.nist.gov/16.4)：仅核查超几何变换背景；没有把未核定的变换当作本阶段证明步骤。

本轮贡献的表述限于将上述已知工具用于既定模型的完整相位和峰面渐近。未完成独立首创性查新，未证明横向邻域、波包积分极限或有限 G 动力学。
