# 三阶导数 singlet：原文与结果归属

本轮于 2026-11-06 实读以下原始论文 HTML 的相关段落。未下载或修改此前缓存原文。

1. Miyashita–Sekino–Susskind, *Holograms and Standard Models*, [2607.05678v2](https://arxiv.org/html/2607.05678v2)，§4.3，(4.19)–(4.26)。该节提出导数 singlet 家族、定性 n=3 指认，并把定量谱比较列为检验。本文没有提供我们所需的同 J 三阶 Gram/实时核。沿其问题做计算，不把定性指认当定量谱结果。当前标准 CAR、L=adH 的 i^n、p 因子在本地稿中另推。

2. Berkooz–Narovlansky–Raj, *Complex Sachdev–Ye–Kitaev model in the double scaling limit*, [2006.13983v2](https://arxiv.org/html/2006.13983v2)，§7 (7.1)–(7.3)、§7.1。原文明确探针 J^(M) 与 Hamiltonian J 不相关。我们构造的 R 为 J 的三次多项式，因此不能把独立探针条件直接认给它。本轮只以已有探针 crossing rule 比较九个已算双边矩；完整 q³ Mehler 核留待任意阶归约。
