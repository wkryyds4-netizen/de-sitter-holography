# 固定电荷范数的前驱与本轮使用

2026-11-06实际重读 [Kota–Vyas, arXiv:1504.00759](https://arxiv.org/pdf/1504.00759)，§2，PDF页7–8，(8)–(14)：两种covariance分解、Racah换道与四阶Gaussian收缩；也读取§3，PDF页12–13的(29)–(32)组织方式。采用其有限N covariance框架，不采用稀薄极限，不把已有EGUE第四矩当本项目新公式。

本轮交换Casimir恒等式另给直接推导：Phi的trace自伴性和equivariance使交叉Leibniz项精确消失。这个插入公式、相邻charge Rem范数与上一轮coherent cross组合，产生实际A的fixed-half-filled范数。没有检索证据足以声明原创优先权。

本地输入：memory-coherent-cross的xi及BA/SA；memory-parity-gram的S范数和JhF桥接；memory-charge-lift的ell_r；cubic-linear的omega精确比与factorial tail。旧singlet-kernel的full-Fock variance只在末尾比较结果，不作为fixed-sector AA极限的输入。

此前缺口是先保留两个charge间的大项抵消，再控制p²放大后的余项。本轮明确用logarithmic growing windows和factorial tails解决；没有凭有限小系统或仅点态系数收敛推出全rank极限。
