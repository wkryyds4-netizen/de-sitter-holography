# 移动阈值曲线：来源与本轮计算边界

2026-10-30。本轮先重读项目中的第12、13节、静态路径积分及前轮阅读记录，并在线核对 [Kolchmeyer–Liu 2411.08090v1](https://arxiv.org/html/2411.08090v1) 与 [DLMF 5.2](https://dlmf.nist.gov/5.2)。原文继续采用[既有缓存](../sources/kolchmeyer-liu-2411.08090v1.html)，没有新增来源缓存。

KL 的模型、交叉核及对数时间分析是前驱；每次插入移动硬阈值、指数外密度及其角点分析是本项目明确指定的后续计算。DLMF 提供 Gamma 的 Euler 表示与极点事实。新的分区式是对既有 J_Q 的代数重写；本轮没有提出新的基本动力学，也不据数值支持宣称原创性。

本轮计算的是第13节模型内的真实完整积分。原文的微正则外窗不能替换逐次投影；固定阈值 F 的轮廓变形也未移植到 Q。实轴时间相位保持 t_M=log(2M)+T，没有拟合时间平移。

前轮已经推导逆三次系数，本轮用完全独立于该系数的积分生成曲线，再比较比值。不同分区共享 Gamma 实现，不能称作独立特殊函数认证；求积加阶是经验数值证据。一般密度端点、有限 M 窗口及有限 G 对应仍开放，系统查新未在本轮完成。

参见[本轮推导与结果](../notes/stage3-moving-threshold-curve.md)、[LaTeX](../manuscript/movingcurve.tex)及[计算入口](../code/moving_threshold_curve.py)。
