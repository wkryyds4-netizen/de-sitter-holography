# 体介子靶标：本轮实际阅读位置

2026-11-06。均为作者原文，在线读取，无新全文缓存。

1. [Miyashita–Sekino–Susskind 2607.05678v2](https://arxiv.org/html/2607.05678v2)，§4.1–4.3：(4.1) 的裸/重整化质量差；(4.15)–(4.18) 固定张力的零重整化质量极限；其后脚注明确不是手征极限，并直接引用 FLZ。§4.3 是 singlet 算符族及尚待定量谱比较。本轮核对的这些段落没有提供当前 X/Rhat 的空间平移算符。此前主线表只写了“求原始介子方程”，现在已接到特定 a=0 规范。
2. [同作者 2506.18054v3](https://arxiv.org/html/2506.18054v3)，§5.1–5.3 的参数、平面与平直极限，以及 §6.2 的 string breaking/meson escape 描述。其图示不等于空间重建核。§6.1 的相变位置已由 [2511.10907v1](https://arxiv.org/html/2511.10907v1) 更正；不重新使用旧弦尺度位置。
3. [Fateev–Lukyanov–Zamolodchikov 0905.2280v2](https://arxiv.org/html/0905.2280)，实际读取 §1 (1.1)–(1.5) 的谱方程和规范；§2 (2.1)–(2.3) 的 logit Fourier 变换；§5 的 Chebyshev 方法及表 1/2 的前六个数值；Appendix B (8.5)–(8.7) 的对称 Fredholm 核。将原文 λ 改记 ν，原文 g² 对应本项目体 τ。我们复现现成方法和谱，不宣称新发现 ’t Hooft 质量谱。

本轮新增整理：由标准有限部分式得到正二次型，以 min–max 给 a=π/p² 的相对谱界；把既有质量靶标放进一介子 Poincare 表示，并将反向光锥响应的一二阶矩写成可检验的质量方差条件。这些是标准数学/运动学方法在当前方案的应用，未检索或声称优先权。微观 DSSYK 重建和有限 λ 动力学依然待构造。
