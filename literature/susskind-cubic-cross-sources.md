# 三阶交叉谱：来源与使用边界

2026-11-06，先读现有推导，再确定新增计算。正式稿见 manuscript/susskind-cubic-cross/main.tex。

1. V. K. B. Kota, [arXiv:2208.11312v2](https://arxiv.org/html/2208.11312)，实际核读 §IV (28)–(31) 及其后四次矩讨论。使用既有 U(N) 两种协方差分解、Λν 的二项式表达及 rank multiplicity。κν 和 ων 是已有 embedded-ensemble 输入，不能写成我们的原创公式。本文针对 J_HA 的 sν 映射和中心化余项由本项目具体插入推导；没有将原文两个 density traces 的关联与本项目 strength density 混同。
2. Jarod Tall、Steven Tomsovic, [arXiv:2604.14522v2](https://arxiv.org/html/2604.14522v2)，实际核读 §3.1 (3.1)–(3.14)。其正交多项式 Wick product 与 q-Hermite 构造提供现成前驱。必须区别有限 N coupling-chaos W₃H³ 与 H 的标量正交多项式：本轮 B_Z 正是这两类操作之间的非守恒线性差。本文不把 q-Hermite 构造改称新结果。
3. 项目现有 cubic-linear / cubic-dynamics / linear-kernel：使用 tν、完整 rank weights、Poisson deficit 与尾界、F 的 r=q 全核。cubic-kernel 使用任意阶 spectator 提出证明和穷尽模板；本轮变更 RS/RZ 的系数，不重做前轮 RR 核。singlet-kernel 提供 Y 的 r=q² 正测度。

新增计算的准确范围：同一个 H 的具体导数复合物 S、Z、F 间有限系统交叉矩；S/Z 精确线性反项及 O(1/p) 极限；R–S/R–Z 全阶相消和由谱绝对连续性推出的 R–Y 零交叉谱。谱 Cauchy–Schwarz、紧性及矩确定性使用标准方法，不主张这些数学工具原创。

本轮没有做整个 de Sitter 文献的新一轮全景查新，也没有确立上述具体推导的文献首创性。ν_FR、ν_FY、混合高点及 bulk 字典为接续任务。未用单一两点衰减认定 bulk mass。
