# 奇偶矩与 Racah 差分：来源

2026-11-06实际核读：

1. [Koekoek–Swarttouw，1998作者托管报告](https://tudelft.roelofkoekoek.nl/documents/as98.pdf)，§1.2，PDF第30页，(1.2.5)及其B(x)、D(x)：本轮采用其既有差分方程，参数α=β=−m−1、γ=−N−2、δ0。半填充端点先消去共同因子再取j=m，不把原式0/0直接代入。
2. [作者的报告说明页](https://tudelft.roelofkoekoek.nl/askey.html)与[arXiv早期报告](https://arxiv.org/abs/math/9602214)用于版本定位；实际公式取1998作者PDF。网页/原文提取文本可读，本轮没有声称原文截图视觉检查。

本轮最初查看DLMF18.22以寻找差分式，该节未包含所需Racah条目，随后转作者原报告；不把DLMF该节列为此公式依据。

本地前驱：memory-rank-blocks的正π、Racah三重和及普通矩/尾；memory-charge-lift的τ选择规则；memory-two-charge的S_N及Hpart L²结果；cubic-linear的输入缺额权重和F bridge。

本文的新计算定位为这些既有工具在记忆输出缺额上的应用：半填充signed transform、signed Casimir矩和实际same-J Gram。没有声称首次提出Racah差分方程、particle-hole symmetry或Poisson分布。
