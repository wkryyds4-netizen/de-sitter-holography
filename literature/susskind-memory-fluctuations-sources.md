# memory-fluctuations来源核查

2026-11-06。新外部文献重点为已有q-Mehler条件期望与Markov算符，避免把标准概率核当新模型。

- M. Bożejko, B. Kümmerer, R. Speicher, *q-Gaussian processes: non-commutative and classical aspects*, [funct-an/9604010v1 PDF](https://arxiv.org/pdf/funct-an/9604010)。实际阅读Theorem1.10及4.6、正文20–22页：正Mehler transition、Hermite本征值r^n、自伴L²作用。P_rP_t=P_(rt)由同一Hermite基直接得到；本文用于能量函数回归，不宣称真实记忆时间构成Markov半群。
- M. Berkooz, V. Narovlansky, H. Raj, [Complex SYK in the double scaling limit, 2006.13983v2](https://arxiv.org/html/2006.13983v2)。q-Hermite/Mehler probe谱延续上轮已核来源。本轮不另假设独立带电probe，weighted mean沿用已建立的同J force测度极限。

- [memory-force](../notes/susskind-memory-force.md)：正force测度、两memory-force界、charge尾与精确Z1。
- [cubic-cross](../notes/susskind-cubic-cross.md)：有限N P_m、R/F/B_S/B_Z归约和rank余项。
- [filtered-spectrum](../notes/susskind-filtered-spectrum.md)：F/Y/R交叉双能量测度消失，对角谱权、能量与时间后代规范。
- [singlet-kernel](../notes/susskind-singlet-kernel.md)：Y通道；[linear-kernel](../notes/susskind-linear-kernel.md)：F通道；[cubic-kernel](../notes/susskind-cubic-kernel.md)：R通道。

本轮贡献范围：已知Markov核在指定memory对象上的能量回归及scalar-centering下界；明确有限N counterterms后首对memory系数的谱矩阵。这些是本项目内推导，不作优先权声明。尚无完整finite-memory涨落或体质量字典。新PDF仅在线阅读，未新增原文缓存。
