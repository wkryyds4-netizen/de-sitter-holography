# 二次收缩的原文核对

2026-11-06 实际在线核读：

1. [Kota, arXiv:2208.11312v2](https://arxiv.org/html/2208.11312)，§IV (29)–(32)：embedded GUE 协方差的两种 U(N) 耦合及 Λν 组合数。使用其精确二阶协方差；没有把后续近似高矩作为完整动态谱证明。
2. [Tall–Tomsovic, arXiv:2604.14522v2](https://arxiv.org/html/2604.14522v2)，§2.1 (2.11)–(2.19)：rank 分解及 sandwich covariance；§3.1 (3.1)–(3.14)：其 Wick 多项式按 Hamiltonian 谱正交定义。在当前 finite-N coupling-chaos 问题中，不能直接用谱 q-Hermite 多项式替代逐 Gaussian 坐标收缩。

本轮应用：保留同一独立副本在相邻 charge 的相关性，用完整 Psi(X)=E uXv 及中性 Phi 构造 quartic core 的六种单配对收缩。Gaussian heat/normal-ordering 是标准工具；具体 core 的五字公式、协方差组合及有限 residual Gram 为本项目本轮推导，未声称排除全世界文献中的等价形式。

已有输入：notes/susskind-memory-quartic.md 的 core/renewal，notes/susskind-cubic-linear.md 的 F，notes/susskind-cubic-cross.md 的旧后代与守恒部分。本轮有限结果没有假定独立 probe，也未借用独立 probe 的 Mehler 公式来给剩余二次场指定全谱。

下一文献任务：在 general-N 双输入不可约张量乘法／Racah 收缩中定位可复用公式；需要两个输入 rank 和一个输出 rank，只有单个 κν 渐近不够。随后才确定残量的 DS 强度和谱。
