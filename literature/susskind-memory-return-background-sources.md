# memory-return-background 来源与适用范围

2026-11-06。先核已有条件期望与多 probe 公式，再构造实际共同 J 的强桥接。

- Bożejko–Kümmerer–Speicher, *q-Gaussian processes: non-commutative and classical aspects*, [funct-an/9604010v1](https://arxiv.org/pdf/funct-an/9604010)。本轮协作核读 Theorem1.10（PDF7–8页）、Prop2.9（10页）、Theorem2.10(2)证明（11–12页）、Theorem2.11（13页），并接4.6证明（21页）。Mehler/Hermite本征值与正交投影的保迹条件期望已有；spectator sandwich 的 q^n 是这些公式的直接推论。双指定 bubble 的乘积由两次条件期望得到。此文不证明本项目实际同 J 力插入的有限 N 压低。
- Berkooz–Narovlansky–Raj, *Complex Sachdev-Ye-Kitaev model in the double scaling limit*, [2006.13983v2](https://arxiv.org/html/2006.13983v2)。§3为complex chord规则；§7(7.1)–(7.3)明确 probe 随机系数与 H 不相关，大小 double scaled；§8.1为neutral multiprobe。不能直接用独立 probe 四点式替换 Fi=[H,ci] 的全部共同 J 配对。
- Berkooz–Isachenkov–Narovlansky–Torrents, *Towards a full solution of the large N double-scaled SYK model*, [1811.02584v2](https://arxiv.org/html/1811.02584v2)。§4.1(4.9)给uncrossed三能量积分，支持本轮两个指定bubble的现成谱结构。§4.2及footnote8提醒 crossed式省略了整体probe crossing因子；本轮未调用该crossed式作次领先结果。
- Jiuci Xu, *On Chord Dynamics and Complexity Growth in Double-Scaled SYK*, [2411.04251v3](https://arxiv.org/html/2411.04251v3)。本轮另查§3.4(107)–(109)的有限时间crossed/chord-number接口、(111)–(113) light-probe极限，作为下一步检索线索。未把它们代入当前共同 J 次领先场；正文证明不依赖该来源。最终回读arXiv摘要页校正初稿混入的另一论文标题，ID及实际所查公式不变。
