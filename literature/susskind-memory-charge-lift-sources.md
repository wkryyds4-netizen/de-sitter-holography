# charge lift 与乘积通道：来源核读

2026-11-06，本轮实际打开原文：

- [Kota–Vyas 1504.00759](https://arxiv.org/pdf/1504.00759)，§3，PDF第14–15页，式(34)/(35)及紧邻文字：coupled product 的 reduced matrix element 保留 multiplicity ρ，经 U(N) Racah 系数表达。本轮使用其结构组织两个电荷的振幅；未把 dilute limit 用于半填充 DS。浏览工具读取了对应原文提取文本；未声称本轮逐页视觉阅读原文。
- [Kota 2208.11312v2](https://arxiv.org/html/2208.11312)，本轮重新打开以确认既有 embedded covariance 背景；具体协方差规范继续沿用本项目此前核读的 §IV。未把 spectral density two-point 当作 memory correlator。

本轮选择规则用 CAR、signed complement 和 Schur 原理直接证明；反例与 removal singular value 为对既有结构的具体计算。没有对其文献首创性作声明，也未把 τ 选择规则称为新的物理定律。

本地前驱：memory-quadratic-contraction 的完整 Q_Ecal 和独立 polarization；memory-rank-blocks 的 Casimir projectors、π_ab 正乘积律及 sym/decoupling 上界；cubic-linear 的 primitive embedding 系数与 charged covariance。旧 N5 结论原本就限定有限系统，本轮否定的是其一般 scalar-filter 推广。
